# Weather Application

## About the Project

Weather Application is a simple and interactive website that allows users to check current weather information by entering a city name.

## Features

- Search weather by city name
- Display current temperature
- Show humidity percentage
- Display wind speed
- Show weather conditions
- Weather icons
- Responsive user interface
- Real-time weather information using an API

## Technologies Used

- HTML
- CSS
- JavaScript
- Open-Meteo Weather API

## API Used

Open-Meteo API:
https://open-meteo.com/

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Enter a city name.
5. Click Search to view the weather.

## Project Structure

- index.html - Website structure
- style.css - Website design
- script.js - Weather functionality
- README.md - Project documentation
